# Hi, I'm Jeffrey Martins 👋

AI Adoption Lead / Solutions Engineer — I design and ship production AI systems that don't hallucinate, because they're grounded in real data instead of guessing.

## What I build

- **Heffra** — a multi-agent B2B lead-qualification platform for French independent professionals, grounded on live INSEE/SIRENE company data.
- **CADASTRA** — a French property-zoning and transaction-history tool, chained entirely through public geocoding, cadastre and sale-record APIs.
- [**anchored-lookup**](https://github.com/13tinsmar-dot/anchored-lookup) — a small, open-source example of the pattern behind both: grounding an LLM's answer in a verifiable source before generation, instead of catching hallucinations after the fact.

## How I work

I care about one thing above all: an AI system should never state a wrong answer with confidence. That means:

- Anchoring answers in verified external data at generation time, not policing them afterward with a second "checker" agent
- Returning `null` rather than a plausible-sounding guess when the data doesn't support an answer
- Strict, typed outputs (JSON schemas) so downstream systems can trust what they get
